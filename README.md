## 🗄️ SQL Learning Journey

This repository documents my progress as I learn SQL from the ground up using PostgreSQL. Each session folder contains my notes, practice queries, and exercises as I work through the course — from the very basics of relational databases all the way to window functions and stored procedures.

> 🚧 **This is a work in progress!** I'm actively updating this as I complete new sessions.

## 🎯 Why I'm Learning SQL

SQL is one of the most in-demand skills in data, and I want to build a solid foundation before moving into data analysis or engineering roles. This course is helping me understand not just *how* to write queries, but *why* they work the way they do.

## 📚 Course Overview

This portfolio is organized into 13 progressive sessions, each building on the last to develop a well-rounded SQL skill set.

| # | Session | Topics Covered |
|---|---------|---------------|
| 01 | Intro to Relational Databases | Database concepts, tables, relationships, primary/foreign keys |
| 02 | Intro to PostgreSQL | Setup, psql CLI, pgAdmin, basic queries |
| 03 | Data Types & Constraints | VARCHAR, INTEGER, BOOLEAN, NOT NULL, UNIQUE, CHECK |
| 04 | Filtering | WHERE, AND/OR/NOT, IN, BETWEEN, LIKE, IS NULL |
| 05 | Numeric Functions | ROUND, CEIL, FLOOR, ABS, MOD, arithmetic expressions |
| 06 | String Functions | CONCAT, UPPER/LOWER, TRIM, SUBSTRING, REPLACE, LENGTH |
| 07 | Date Functions | NOW, CURRENT_DATE, AGE, DATE_PART, DATE_TRUNC, intervals |
| 08 | JOINs | INNER, LEFT, RIGHT, FULL OUTER, CROSS, self-joins |
| 09 | Advanced SQL | Subqueries, CTEs, CASE statements, COALESCE |
| 10 | Advanced SQL Functions | Window functions (ROW_NUMBER, RANK, LAG, LEAD, PARTITION BY) |
| 11 | UDFs & Stored Procedures | User-defined functions, PL/pgSQL, stored procedures, parameters |
| 12 | Advanced Aggregations | GROUP BY, HAVING, GROUPING SETS, ROLLUP, CUBE |
| 13 | Final Project | End-to-end data analysis project using real-world dataset |
